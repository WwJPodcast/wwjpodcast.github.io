# beds

Background music beds for the Walking with Jesus player.

- Music by **andrii g.** (andriig) from [Pixabay](https://pixabay.com/users/andriig-54059306/), used under the [Pixabay Content License](https://pixabay.com/service/license-summary/).
- 47 tracks, about 106 minutes in total. Each source track is roughly two minutes, so the player loops and rotates them.
- Re-encoded to 128 kbps MP3 and level-matched to about -20 LUFS, so one volume slider behaves the same on every track.
- `beds.json` lists every track with its mood group, Pixabay title and genre, length, and source page.
- Files are named `<mood>-<pixabay id>.mp3`. Mood groups come from Pixabay's titles and tags, not from listening, so audition before relying on them.
- Pixabay shows these tracks as registered with YouTube Content ID. If a video that uses one is ever claimed, Pixabay offers a license certificate on each track's page.
